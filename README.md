# Kuuttila Bar | Helsinki

[![Website Status](https://img.shields.io/badge/Website-Active-success.svg)](#)
[![Tech Stack](https://img.shields.io/badge/Framework-HTML%2FCSS%2FJS-orange)](#)

A highly customized, premium landing page designed for **Kuuttila Bar**, a neighborhood cocktail lounge based in Helsinki. The website serves as a digital representation of Kuuttila's unique "livingroomish" aesthetic—intimate, handmade, and exclusive.

## 🍸 About the Project

The design philosophy mirrors the atmosphere of minimalist boutique cocktail bars in New York City. The UI heavily utilizes a dark, moody background offset by warm, vibrant neon lighting, bringing the physical experience of the lounge to the digital space.

### Key Features
*   **Immersive Design**: A custom, high-contrast visual hierarchy targeting premium audiences.
*   **Responsive Layout**: Perfectly fluid scaling across mobile, tablet, and desktop viewports.
*   **Instagram Integration**: Pre-configured structure to dynamically pull the latest posts from Instagram, acting as an evolving gallery to showcase craft cocktails and events.
*   **Private Events & Catering**: Dedicated conversion sections detailing off-site high-dining options and intimate closed events.

## 🛠️ Technology Stack

*   **HTML5**: Clean, semantically structured markdown.
*   **Vanilla CSS3**: Tailored styling ensuring blazing fast load speeds without unnecessary framework bloat.
*   **Vanilla JavaScript**: Lightweight DOM manipulation for active navigation and smooth intersection animations.
*   **Elfsight**: Ready-to-use widget container for social feed syncing.

## 🚀 Deployment & Usage

Because the project utilizes native web technologies, it is ready to be deployed instantaneously to any static hosting provider (e.g., GitHub Pages, Vercel, Netlify).

1. Clone the repository.
   ```bash
   git clone https://github.com/andrgavrilenko/kuuttila.git
   ```
2. Open `index.html` in your web browser.
3. Configure the `YOUR-WIDGET-ID` parameter in the `index.html` Instagram section to link your live feed.
